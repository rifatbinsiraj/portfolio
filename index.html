Open-source npm packages

Small tools for keeping Node.js projects and CI pipelines safe and tidy.

  • vuln-guardian

    Finds vulnerable npm dependencies in a project and applies the safe fixes.

  • secrets-guardian

    Catches leaked API keys and credentials in a repo or staged files before they reach history.

  • postinstall-guardian

    Lists install scripts in node_modules, the most common npm supply-chain attack path.

  • license-guardian

    Fails CI on copyleft or unknown dependency licenses that are not on your allow list.

  • actions-guardian

    Finds GitHub Actions pinned to movable tags and pins them to a commit SHA.

  • crashrelay

    Turns back-end crashes, 5xx responses and error logs into Jira or GitHub issues, without duplicates.

  • crashrelay-browser

    A tiny, dependency-free snippet that reports browser errors to crashrelay.

  • files-to-markdown

    Converts PDF, Word, Excel, CSV, HTML, JSON, text and images to clean Markdown.

  • api-collection-converter

    Converts API collections between Postman, Swagger, OpenAPI, Insomnia and HAR.
